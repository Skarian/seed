# Seed reference collection

Public interface examples collected November 3, 2026. These are independently published screenshots, not the user's history, media, projects, or account. They are historical and may differ from current products. Copyright remains with their publishers. Open `mosaic.html` for a visual overview. These are selected states, **not complete captured flows**. Pixel dimensions do not establish viewport width or device type.

## Recommendations

- **Midjourney:** group variations for comparison; put reuse, vary, and edit on the selected result. Its Organize view offers saved searches and folders. Simplify its dense action list for Seed.
- **ChatGPT Images:** use a focused image view with an edit action and natural-language follow-up attached to the image. These 2025 examples show a sparse library, not large-library scalability.
- **Runway:** study session context, direct reuse, and optional lineage. Do not make the advanced workflow graph the default creative interface.
- **Runpod:** compare GPU capacity and price; disclose compute and continuing storage charges before committing; make availability queues and instance lifecycle explicit. Avoid importing the entire infrastructure console.
- **Seed-specific proposal, not an observed flow:** make the agent's request, inputs, model, estimated cost, and explicit approval editable together before execution. Show named job states, cancellation consequences, and an obvious way to reuse an output.

## Coverage gaps

- **Replicate, Modal, Lambda:** no dashboard screenshots. Their docs are text or script-rendered and exposed no usable images (Lambda's docs moved to docs.lambda.com). Vast.ai and Runpod are the only compute-console evidence.
- **True generation lifecycle:** Luma shows "dreaming" and "in queue" states from two separate articles, not one flow. There is no captured queued, running, finished and failed sequence, and no cancel-with-credit-consequence beyond the Runway crop.
- **Approve/edit of a generation request:** no verified screenshot shows an agent proposing an image or video request with editable model, inputs and cost. Cursor's plan card and Claude's approval list are analogies from coding.
- **Not covered at all:** real UI for Runway, Pika, Sora and Google Flow (tutorial pages had no usable images; the OpenAI help center blocked download; one search result said the Sora app was discontinued in April 2026, unverified), Firefly and Freepik web, Leonardo web, Apple Photos, Lightroom library, Framer, ChatGPT canvas, Claude artifacts, and Midjourney at tablet width.
- **Mobile and tablet:** evidence is App Store composites (small text, curated content) plus the earlier ChatGPT library crop. There is no verified real-device capture of a job queue or library on a narrow viewport.
- Community screenshots, publisher annotations and older examples are not definitive current UI. Device type is inferred only from the App Store listing category (iPad or iPhone).
