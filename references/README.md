# Seed reference collection

Public interface examples collected November 3, 2026. These are independently published screenshots, not the user's history, media, projects, or account. They are historical and may differ from current products. Copyright remains with their publishers. Open `mosaic.html` for a visual overview. These are selected states, **not complete captured flows**. Pixel dimensions do not establish viewport width or device type.

## Recommendations

- **Midjourney:** group variations for comparison; put reuse, vary, and edit on the selected result. Its Organize view offers saved searches and folders. Simplify its dense action list for Seed.
- **ChatGPT Images:** use a focused image view with an edit action and natural-language follow-up attached to the image. These 2025 examples show a sparse library, not large-library scalability.
- **Runway:** study session context, direct reuse, and optional lineage. Do not make the advanced workflow graph the default creative interface.
- **Runpod:** compare GPU capacity and price; disclose compute and continuing storage charges before committing; make availability queues and instance lifecycle explicit. Avoid importing the entire infrastructure console.
- **Seed-specific proposal, not an observed flow:** make the agent's request, inputs, model, estimated cost, and explicit approval editable together before execution. Show named job states, cancellation consequences, and an obvious way to reuse an output.
