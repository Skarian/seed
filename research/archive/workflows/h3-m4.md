## Existing graph bindings

Its hardcoded center crop must be replaced by the agreed fit/fill preparation.

`deployment/test-ref2va-api.json` instead uses `minimax_h3_ref2va_pruned_int8_convrot.safetensors`, `minimax_h3_ref2v_turbo_8step_v1.0_768p_comfyui_bf16.safetensors`, and `MiniMaxH3ReferenceToVideo`. Its example proves only a single image binding, not the planned mixed-input surface.

Across these graphs: node6 produces conditioning0 and joint AV latent1; BasicGuider7 consumes conditioning; RandomNoise8 supplies seed; KSamplerSelect9 is Euler; BasicScheduler10 is simple/eight steps/denoise1; SamplerCustomAdvanced11 produces the joint sampled latent; VAEDecode12 and VAEDecodeAudio13 both read that joint result using their respective VAEs. Required turbo adapter5 must remain in SFW as well as NSFW. Content adapters belong after5 and their final model must feed BOTH guider7 and scheduler10.

Keep FL and Ref content bindings separate. Existing selected candidates recorded in COMFYUI-CHANGES.md are Civitai version3266628: FL file3150341 and Ref file3156453. ## Native capabilities rechecked

Pinned Comfy source supports Ref images0–8, videos0–2, paired video audio0–2, and standalone audio0–2 through autogrow inputs. Image/video/audio collections retain serialization order; paired sound is matched using the video's numeric suffix. Do not compact paired sound indices independently. API bindings use `ref_images.ref_image_N`, `ref_videos.ref_video_N`, `ref_video_audios.ref_video_audio_N`, and `ref_audios.ref_audio_N`. Generate native prompt labels from the same ordered inputs.

`MiniMaxH3AddGuide` returns CONDITIONING only. Wire its output to guider conditioning while preserving the original joint latent for sampling. It supports image/audio guides and frame indices, including negative indices relative to generated length. Native videos round down to17k+5 frames; generated lengths round up. Audio encoding resamples to the audio VAE rate (default32kHz). `match` reference sizing downsizes preserving aspect; `max` is a distinct slower native option, not a made-up quality tier. ## Export pitfalls

Local `deployment/minimax_app_nodes.py` generates124/243/362 frames, then exports120/240/360 at24fps, resizing1344×768 or768×1344 to exact1280×720 or720×1280. Finish trims audio to exact duration and rejects insufficient frames/audio. The raw Ref2VA test graph bypasses this finish and therefore does not satisfy the same exact-duration/canvas contract.

The native last-frame image is attached to the GENERATED final frame; trimming discards it. Use the already-planned AddGuide candidate at exported indices119/239/359, then judge actual ending-frame influence. Do not claim solved based merely on valid graph execution. Source soundtrack should be a separate local finishing operation after retrieving generated media; silent output should omit the track without implying reduced generation cost.

## Worker terminal and transfer changes required

Current M3 terminal capture recognizes only node9 SaveImage, `history.outputs[9].images`, PNG, and exactly one image. H3 export is node14 VHS_VideoCombine, whose UI history uses `gifs`, not `images`. Current upstream VHS returns one preview descriptor and a separate result tuple containing generated filenames; intermediate silent videos and metadata utility files may also exist. Capture the final preview MP4 only after native success, verify job-owned path and closed artifact, and account for every retained intermediate when cleaning the job directory. Do not mistake the silent intermediate or metadata PNG for the final audio-containing video. Installed VHS revision/schema still requires direct verification; this reference is upstream main, not the pod pin. [VHS exporter source](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite/blob/main/videohelpersuite/nodes.py)

Extend manifest output typing, PC content MIME, Library playback, and frozen output expectations to video/mp4. Remove image-specific `.png` naming and the image-only size bound from the video path; retain bounded streaming and disk-space checks. Preserve original generation output if local source-audio finishing fails, and acknowledge only after required durable artifacts are saved.

Current worker launch whitelist permits only `comfy_seed`. Native H3 extras are built in, but VHS and NeilH3 custom nodes will not load under that list. Explicitly enable the pinned required custom nodes or replace only the small preset/finish nodes with equivalent maintained local code. Do not enable every installed extension.
